# General network-connectivity triage

Gather scope before changing network settings. Network changes can affect shared services and should be performed by authorized network staff.

1. Record the affected device, location, connection type, approximate start time, and exact non-sensitive error.
2. Ask whether a known internal service, the approved intranet, or multiple unrelated services are affected.
3. Check the normal Wi-Fi or Ethernet status indicator and whether nearby colleagues report the same problem.
4. If only one application is affected, route the ticket to its application owner rather than changing network configuration.
5. If several users or locations are affected, notify the network support team with the observed scope and times.

Do not disable endpoint protection, change network security settings, or run unapproved diagnostic commands.
