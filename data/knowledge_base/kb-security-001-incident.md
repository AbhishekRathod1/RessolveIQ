# Escalating a suspected security incident

Treat suspicious messages, unexpected sign-ins, and endpoint alerts as unverified reports. This guide is not an incident-response authority. Only the security team directs containment or account actions.

1. Ask the reporter to stop interacting with the suspicious message, attachment, or link.
2. Record the alert wording, approximate time, affected managed device or account, and how the event was noticed.
3. Do not ask the reporter to forward secrets, delete files, or investigate by opening the suspicious content.
4. Escalate promptly to the organization's security response contact using the approved incident channel.
5. Preserve the original message or device state according to security-team instructions; do not alter evidence.
6. Let authorized security staff decide whether access changes, device isolation, or other response actions are required.

Require human security review. Do not run suggested commands or perform account changes from this article automatically.
