# Collecting details for an application crash

Collect enough information to route a repeatable application failure without collecting confidential document contents.

1. Record the application name and version, managed device type, approximate crash time, and non-sensitive error text.
2. Ask what action immediately preceded the crash and whether the issue repeats with a blank or sample document.
3. Check the approved application status page or internal service notice for a known incident.
4. If permitted, have the requester close and reopen the application normally and retry the same safe workflow once.
5. Route recurring crashes to the application owner with reproduction steps and approved diagnostic references.

Do not disable security controls, delete user data, or run commands copied from unverified advice. Redact personal or confidential content from diagnostic attachments.
