# Troubleshooting a managed installation error

Use this guide when an approved software-catalog installation reports an error. Do not bypass package controls or install from a personal download.

1. Record the application package name, managed device label, installation time, and displayed error.
2. Confirm the device is online and has the organization-approved software catalog available.
3. Check the internal deployment status for a published outage or maintenance notice.
4. If the package is not assigned or the request requires elevated rights, ask the software owner or authorized administrator to review it.
5. Retry only through the normal managed catalog after support confirms the package is available.

Do not share administrator credentials or alter managed installation settings. Include only redacted diagnostics in the escalation.
