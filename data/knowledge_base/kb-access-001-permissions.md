# Reviewing access-permission requests

Use this guide for a request to view a shared folder or business application. Access changes are privileged: verify the requester and require approval from the resource owner before an authorized administrator changes membership. Never ask for a password or MFA code.

1. Record the exact resource name, the requester's work account, and the task that requires access.
2. Confirm the requester is signed in to the expected organization account and can describe the access error.
3. Check that the resource owner has approved the requested role and scope.
4. Route approved changes to an authorized access administrator; grant only the minimum required role.
5. Ask the requester to verify access and record the approver and outcome in the ticket.

If ownership or approval is unclear, leave access unchanged and request human review.
