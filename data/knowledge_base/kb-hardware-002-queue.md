# Stalled printer-queue requests

Use this article when print jobs remain pending or show an error in the managed print queue. Queue changes can affect other users, so avoid clearing shared jobs without authorization.

1. Confirm the printer name and whether the requester selected the intended managed queue.
2. Ask whether other users can print to the same queue and record the approximate time of failure.
3. Have the requester cancel only their own duplicate job using the normal print interface.
4. Route a shared-queue failure to the print administrator; do not restart queue services or remove other users' jobs.
5. After support confirms the queue is available, submit one small test page if permitted by local policy.

Include only non-sensitive job details in the ticket. Escalate recurring device errors to the hardware team.
