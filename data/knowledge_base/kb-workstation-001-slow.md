# Initial checks for a slow computer

Use these non-invasive checks for a managed workstation. Do not disable endpoint protection or remove files to try to improve performance.

1. Ask when the slowdown began, which approved applications are affected, and whether it happens continuously or intermittently.
2. Record the device asset label and whether the issue affects one user or several devices.
3. Check for a published service notice and ask the requester to save work before a normal restart if appropriate.
4. Have the requester close unused applications through their standard interface and observe whether performance improves.
5. Route recurring slowness to desktop support with the time, application names, and any approved device-health message.

Only authorized support staff should review device health, storage use, or security alerts. Do not ask users to delete unfamiliar files.
