# Email synchronization checks

Use these checks when a supported mail client is not showing recent messages. Do not ask the requester to forward confidential mail or share an authentication code.

1. Confirm whether the issue affects the approved webmail view, the desktop client, or both.
2. Check the device's network connection and whether the mailbox is near its published storage limit.
3. Ask the requester to note the last successful synchronization time and any non-sensitive error text.
4. Have the requester use the client's normal refresh or synchronization control; avoid deleting a profile or cached data without approval.
5. If webmail works but one managed client does not, route the case to messaging support with the client version and device details.

If several users are affected, report the scope to the messaging team rather than changing individual settings repeatedly.
