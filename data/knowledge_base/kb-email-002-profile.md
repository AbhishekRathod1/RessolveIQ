# Diagnosing a mail-client profile issue

A single managed mail client may stop synchronizing while webmail remains available. Profile removal can discard local state, so use the approved support process before rebuilding it.

1. Verify the mailbox works in the organization's approved webmail service.
2. Record the managed client name, version, device type, and the time synchronization last succeeded.
3. Check the normal client connection and synchronization status without collecting message contents.
4. Ask messaging support to review managed-client diagnostics before removing or rebuilding a profile.
5. If a profile rebuild is approved, confirm the requester understands which locally cached items may need to synchronize again.

Never request an email password or MFA code. Escalate broad outages to the messaging team.
