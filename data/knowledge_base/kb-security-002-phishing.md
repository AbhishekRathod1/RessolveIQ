# Reporting a suspected phishing message

Use the approved reporting control or security channel. Do not click a suspicious link to test it, and do not send passwords or MFA codes to anyone investigating the report.

1. Ask whether the reporter clicked, replied to, or entered information into the message; do not ask them to repeat any secret.
2. Record the message time, sender display name, and whether an attachment or link was present.
3. Use the organization's approved phishing-reporting process to preserve the original message for security review.
4. Escalate immediately if credentials were entered, an attachment was opened, or several users received the message.
5. Have authorized security staff determine whether further account or device actions are needed.

Do not delete the original message unless the security team directs that action. Human review is mandatory for suspected incidents.
