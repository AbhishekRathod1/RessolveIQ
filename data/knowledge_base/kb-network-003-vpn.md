# VPN connectivity troubleshooting

This fictional guide covers connection failures in an approved managed VPN client. VPN access is for authorized users only; never request a password, MFA code, or private key.

1. Confirm the device has ordinary internet access before opening the managed VPN client.
2. Record the client name, displayed error, approximate time, and whether the issue affects one user or several.
3. Verify that the user selected the published organization profile and can reach the approved sign-in page.
4. Use only the client's normal reconnect control; do not change certificates, firewall settings, or network routes.
5. If sign-in is rejected, route the case to identity support; if several users fail, notify network support.
6. Ask authorized VPN support to review gateway status before recommending a client reinstall.

Include no credentials or authentication codes in the ticket. Human review is required before account or VPN configuration changes.
