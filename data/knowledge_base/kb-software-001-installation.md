# Requesting managed software installation

Install software only from an organization-approved catalog. Administrator rights, license assignment, and security review must be handled by authorized staff.

1. Record the software name, publisher, requested version, business purpose, and managed device asset label.
2. Check the approved software catalog for an available package and any published installation notes.
3. If the package is absent or access is denied, submit the request to the software owner for license and security approval.
4. Have an authorized administrator install or assign the package through the managed deployment process.
5. Ask the requester to confirm the approved application launches and record the outcome.

Do not download installers from unverified sites, bypass device controls, or request local administrator credentials.
